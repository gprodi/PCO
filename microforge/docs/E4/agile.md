# Pilotage agile (C16)

**Méthode** : Scrum adapté à un projet individuel — sprints de 2 semaines.

| Rôle | Personne |
|---|---|
| Product Owner délégué / développeur | Gaël Prodi |
| Commanditaire, revue | formateur / tuteur |

| Rituel | Quand | Support |
|---|---|---|
| Planification | 1er lundi du sprint | backlog GitHub Projects (vue « Sprint ») |
| Point quotidien asynchrone | chaque jour (5 min) | journal `docs/E4/sprints/journal.md` |
| Revue + démo | dernier vendredi | compte rendu `docs/E4/sprints/SNN.md` |
| Rétrospective | après la revue | « garder / arrêter / essayer » |

**Outils** : GitHub Projects (backlog, kanban, champ *Iteration*, graphique *Burn up/down* d'Insights),
issues « user story », « bug », « incident ». Tableau partagé en lecture avec le formateur.
