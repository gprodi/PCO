# Veille technique et réglementaire (C6)

Kit complet : `microforge/veille/` (plan, OPML, grille de fiabilité, gabarit, journal, synthèses).

- **Thématiques** : vision embarquée & VLM open-source ; outillage LLM local et sécurité de la chaîne
  d'approvisionnement ; AI Act / RGPD ; accessibilité (RGAA, EAA) & éco-conception (RGESN) ; écosystème maker.
- **Planning** : lundi 9 h–10 h (lecture, notation) + vendredi 15 min (synthèse) ; journal tenu à jour.
- **Outils** : FreshRSS auto-hébergé (profil compose `veille`, import de l'OPML en une commande), flux
  « releases » GitHub, outil `mf-veille` (OPML → flux RSS/Atom avec analyse XML durcie → articles classés par
  thématique, fiabilité et fraîcheur → brouillon Markdown) exécuté chaque lundi par le workflow `veille`
  sur un runner GitHub ; brouillon **systématiquement relu**, vérifié à la source et noté avant publication.
- **Diffusion** : synthèses Markdown structurées (titres, liens explicites) dans le dépôt + message à la promo
  et au formateur.
- **Fiabilité** : grille /7 (auteur, compétence, fraîcheur, sources, structure, accessibilité, recoupement) ; seuil 5.

Dernière synthèse : [semaine 2026-45](https://github.com/gprodi/PCO/blob/main/microforge/veille/syntheses/2026-45.md).
