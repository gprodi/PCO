## T2 — Outillage et sécurité
### Compromission des paquets PyPI LiteLLM (mars 2026)
- **Quoi** : deux versions publiées sur PyPI contenaient un code d'exfiltration d'identifiants ; l'image Docker officielle n'était pas touchée.
- **Source** : [NetSPI — LiteLLM Supply Chain Compromise](https://www.netspi.com/blog/executive-blog/ai-ml-pentesting/litellm-supply-chain-compromise/) — fiabilité 6/7, recoupée.
- **Impact pour MicroForge** : la passerelle LiteLLM (C8) est déployée via l'image Docker, épinglée par digest ; les actions GitHub sont épinglées par SHA.
- **Action** : fait (`microforge/infra/docker-compose.yml`, `.github/workflows/*.yml`).

## T3 — Réglementation
