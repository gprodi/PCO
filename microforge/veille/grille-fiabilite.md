# Grille de fiabilité des sources (C6)

Chaque critère vaut 1 point. **Une source est retenue à partir de 5/7.** Les « signaux faibles »
(forums, réseaux) ne sont jamais cités seuls : ils déclenchent une vérification.

| Critère | Question |
|---|---|
| A. Auteur identifié | Le nom de l'auteur ou de l'organisation est-il indiqué ? |
| B. Compétence / absence de conflit d'intérêts | L'auteur est-il reconnu sur le sujet, sans intérêt commercial direct ? |
| C. Fraîcheur | La date de publication est-elle visible et récente ? |
| D. Sources citées, langue soignée | Les affirmations sont-elles sourcées ? Le niveau de langue est-il correct ? |
| E. Structure | Le contenu est-il structuré (titres, sections, références) ? |
| F. Accessibilité | Le site respecte-t-il les bonnes pratiques (contraste, titres, alternatives) ? |
| G. Recoupement | L'information est-elle confirmée par une autre source de confiance ? |
