Git et Github
Git est un système de contrôle de version décentralisé. Il enregistre toutes les modifications apportées à vos fichiers au fil du temps, vous permettant de revenir à des versions antérieures si nécessaire. Git facilite également la collaboration, car plusieurs personnes peuvent travailler sur le même projet en même temps, en fusionnant leurs modifications de manière ordonnée.
GitHub est une plateforme en ligne qui héberge des dépôts Git. Il offre une interface conviviale pour gérer vos projets, collaborer avec d'autres développeurs, et partager votre code avec le monde. GitHub propose également de nombreuses fonctionnalités supplémentaires, telles que le suivi des problèmes, les demandes de fusion (pull requests) pour examiner les modifications avant de les intégrer, et des outils de gestion de projet.

Environnement virtuel
11
Un environnement virtuel protège votre projet Python des dépendances et des packages du système global. 
Vous pouvez travailler dans votre propre espace isolé.
La commande pip freeze vous permet de générer une liste des packages Python installés dans votre environnement virtuel, y compris leurs versions. Vous pouvez rediriger cette liste vers un fichier texte, généralement appelé requirements.txt en tapant dans un terminal la commande:
pip freeze > requirements.txt
package1==1.0.0 
package2==2.1.0 
package3==3.2.1

Python - Installer une librairie	
15
Commandes pip courantes:
pip install <nom_du_paquet>: Installe un paquet.
pip install -r requirements.txt: Installe tous les paquets listés dans un fichier requirements.txt.
pip uninstall <nom_du_paquet>: Désinstalle un paquet.
pip list: Affiche la liste des paquets installés.
pip show <nom_du_paquet>: Affiche des informations sur un paquet installé.
pip freeze > requirements.txt: Génère un fichier requirements.txt avec la liste des paquets installés et leurs versions.

notebook jupyter versus script python
18
Les notebooks Jupyter et les scripts Python sont tous deux utilisés pour écrire et exécuter du code Python, mais ils ont des objectifs et des fonctionnalités différents.
Notebooks Jupyter (fichier .ipynb):
Orientés vers l'exploration interactive, la visualisation et le partage de code.
Permettent de combiner du code, du texte enrichi, des équations et des visualisations dans un seul document.
Idéal pour l'expérimentation, l'analyse de données et la création de rapports.
Moins adapté aux applications complexes et à la production.
Scripts Python (fichier .py):
Conçus pour créer des programmes et des applications autonomes.
Exécutés de manière séquentielle et peuvent être importés en tant que modules.
Mieux adaptés aux tâches d'automatisation, aux applications web et aux logiciels complexes.
Offrent une meilleure organisation du code et une maintenance plus facile pour les grands projets.

notebook jupyter (JUlia PYthon R)

Importer une bibliothèque pour s’en servir
En Python, import est le mot-clé magique pour accéder aux trésors des bibliothèques ! Il vous permet d'intégrer du code pré-écrit dans vos propres programmes, ajoutant des fonctionnalités et évitant de réinventer la roue.
Voici comment utiliser import :
import nom_de_la_bibliotheque: Importe la bibliothèque entière.
from nom_de_la_bibliotheque import module: Importe un module spécifique de la bibliothèque.
import nom_de_la_bibliotheque as alias: Importe la bibliothèque avec un nom plus court.
